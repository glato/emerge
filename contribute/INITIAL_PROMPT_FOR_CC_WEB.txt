You are working in a forked repository of emerge (https://github.com/glato/emerge), a codebase analysis and visualization tool.

Your mission: Add advanced file filtering capabilities to emerge to enable clean, focused visualizations of large codebases.

## Context

Currently, emerge analyzes ALL files in a project, creating unusable visualizations when there are 60+ files. We need filtering to show only specific subsets (e.g., 9 core files instead of 66 total files).

## Your Task

Implement these features in emerge:

1. **File Inclusions** (NEW) - Whitelist specific files/patterns/directories
2. **Fixed File Exclusions** - Fix existing exclusions that don't work properly
3. **Metric Filters** (NEW) - Filter by SLOC, fan-in, fan-out
4. **Filter Profiles** (NEW) - Reusable named filter sets
